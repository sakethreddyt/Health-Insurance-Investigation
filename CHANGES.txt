MRD CHARGES BILL TRACKING - HOSPITAL PART
=========================================
The investigator can record whether the MRD charges bill is available and, when
available, the amount. This applies to the HOSPITAL part only and is omitted
for CASHLESS claims. The status and amount are included in Excel and PDF exports.

DATABASE CHANGE:
Hibernate ddl-auto=update adds these nullable columns to the existing case_parts
table when the application starts:
  mrd_bill_available BOOLEAN NULL
  mrd_bill_amount DECIMAL(12,2) NULL
Existing rows remain unset (NULL). For a manual MySQL migration, if schema
updates are disabled, run:
  ALTER TABLE case_parts ADD COLUMN mrd_bill_available BOOLEAN NULL;
  ALTER TABLE case_parts ADD COLUMN mrd_bill_amount DECIMAL(12,2) NULL;
